# Screenshot Placeholders

Replace these placeholders with rendered dashboard screenshots after a browser capture is available:

- `overview.png` - Overview page with metrics, model health, critical events, latency, and throughput.
- `live-events.png` - Live Events page with severity/type filters and payload detail.
- `nodes.png` - Inference Nodes page with node health table and detail drawer.
- `failures.png` - Failures page with summary cards, triage table, and failure detail drawer.
