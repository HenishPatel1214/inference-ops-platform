# Benchmarking

The benchmark script measures client-observed latency for batches sent to the traffic simulation endpoint. It also prints failure counts generated by the simulated inference workload.

## Run

```bash
make up
make benchmark
```

Equivalent direct command:

```bash
cd backend
python scripts/benchmark.py --url http://localhost:8000 --token dev-token --requests 250 --batch-size 10
```

## Sample output

```text
Inference Ops benchmark
requests=250 failures=19 elapsed_seconds=3.42
client_avg_ms=13.17
client_p50_ms=11.82
client_p95_ms=24.39
client_p99_ms=31.06
```

## Interpreting results

- `client_p95_ms` is API round-trip time per simulated request, not model execution time.
- Request rows also store simulated model latency in `inference_requests.latency_ms`.
- Use `/api/analytics/latency` to inspect p50, p95, and p99 by model.
